# Ejercicios Ingrid
Ejercicios sobre PyGame, PyQt5., Kivy, etc.

1. **Atrapa manzanas:** Juego desarrollado con PyGame para repasar creación de Sprites, colisiones, contadores y tiempo de juego.

2. **Lista de tareas:** Repaso de una aplicación desarrollada anteriormente en PyQt5.

3. **Conversor Celsius-Farenheit:** Conversor de temperatura desarrollado en Kivy.

4. **Calculadora de propina:** Calculadora simple con funcionalidad desarrollada en Python y uso de KVLang para el diseño de interfaz.
